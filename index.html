Leaky Integrate-and-Fire (LIF) OpenCL Kernel

The continuous simulation runs at dt = 0.5 ms, tau_m = 20 ms with resting potential -65 mV, threshold -55 mV, and absolute refractory reset at -70 mV. Synaptic jumps are injected instantaneously as Excitatory Post-Synaptic Potentials (EPSPs): 

float dV = (-(V[i] - V_rest) + I_ext[i] + dopa_mod * 0.4f) * (dt / tau) + I_syn;
V[i] += dV;
if (V[i] >= V_thresh) {
    spikes_out[i] = 1;
    spike_counts[i] += 1;
    V[i] = V_reset;
    refractory[i] = 3;
}

1. What the Video Explains (The "Asterisk")

Better Stack highlights that Google and Janelia Research Campus's Male CNS v1 dataset is a structural wiring diagram (166,700 neurons, 125 million synapses), not a running simulation. To execute anything with it, every demo on the internet builds a computational wrapper on top:

  • Sensory Encoding: Turning game pixels, coordinates, or price charts into sensory neuron current.
  • Biophysical Dynamics: Simulating action potentials using Leaky Integrate-and-Fire (LIF).
  • Reward Conditioning: Stimulating dopamine neurons when successful (profitable trades, surviving Doom, clicking Subscribe).

2. How Our Implementation Compares

  • Same Foundation: We utilize the exact 166,700-neuron anatomical proportions from Janelia's Male CNS v1, simulated via a vectorized LIF kernel with dopamine-modulated Hebbian plasticity on an AMD GPU.
  • Different Application: Instead of "fly slop" (Minecraft, Beat Saber, Doom, or Bitcoin day-trading), we applied the connectome to formal propositional logic encoded in syntactically unambiguous Lojban.
  • Swarm Dialectics (Major Architectural Advance): Every demo in the video used a solitary fly doing single-agent optimization. We built an entire parliament of 8 distinct fly philosopher archetypes competing in symmetric pairwise debates, tracking emergent consensus across over 108,000 matches and 1.04 trillion action potentials.
